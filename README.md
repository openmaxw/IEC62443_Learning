**面向销售、产品经理、FAE 与 TS 新人的 IEC 62443 场景化学习与演示平台。**

本系统基于项目案例组织内容，帮助公司内部新人理解 IEC 62443 在客户沟通、需求转译、方案响应、能力说明与差距闭环中的实际表达方式。它的目标不是替代正式标准培训，而是让用户先建立项目语境、岗位认知和跨角色共同语言。

## 系统定位

本系统适合用于公司内部新人培训、案例演示、售前赋能和跨部门沟通。

它的核心价值不是输出合规结论，而是帮助用户沿着一个可理解的案例链路，逐步回答以下问题：

```text
客户为什么会提出安全诉求
  -> 如何把诉求说成项目输入
  -> 方案团队如何形成响应
  -> 产品能力如何映射到需求
  -> 差距与补偿措施如何解释
  -> 如何形成可复用的学习总结
```

换句话说，本系统更像一个“岗位赋能与案例演示工作台”，帮助新人通过具体情境看懂 IEC 62443 在项目前期是如何被讨论、转译和说明的。

## 适合谁使用

### 销售新人

适合需要快速理解客户安全诉求、识别机会并建立对话框架的销售或售前新人。

系统可以帮助他们：

- 理解客户常见关注点，例如远程维护、第三方接入、审计压力和责任边界
- 学会从客户场景出发提问，而不是直接抛出抽象标准术语
- 识别哪些信息需要进一步交给产品经理、FAE 或 TS 深化

### 产品经理

适合需要把产品能力映射到项目需求，并向跨团队说明适用边界的产品角色。

系统可以帮助他们：

- 理解项目输入如何转化为能力需求
- 学会用“满足情况、证据、依赖、限制”来表达产品能力
- 用案例说明产品价值和能力边界，而不是只罗列功能点

### FAE / TS

适合需要把技术能力、方案约束和实施前提讲清楚的现场支持与技术支持角色。

系统可以帮助他们：

- 将客户诉求转译为分区、通信、边界控制、日志审计等技术响应点
- 提前识别账号管理、远程访问、日志留存等依赖条件
- 用差距分析和补偿措施说明为什么某些项目要求不能只靠单一产品解决

### 培训讲师 / 顾问 / 团队负责人

适合组织内部培训、带领新人演示案例、统一团队表达口径的角色。

系统可以帮助他们：

- 用同一案例支撑 5 分钟导览、15 分钟演示和岗位化训练
- 组织销售、产品、FAE、TS 在同一案例上建立共同理解
- 将案例讨论结果沉淀为团队可复用的培训材料

## 推荐使用方式

### 5 分钟快速导览

适合第一次接触平台的用户。

1. 进入 **学习总览** 了解案例背景
2. 查看 **追溯视图** 理解完整链路
3. 在 **学习总结** 中查看关键结论

### 15 分钟案例演示

适合主管、讲师或售前负责人进行快速培训。

1. 从 **客户诉求** 说明客户为什么会提出工业安全问题
2. 在 **方案转译** 中说明方案团队如何回应这些诉求
3. 在 **能力说明** 中说明产品能力、证据和边界
4. 在 **差距分析** 中说明满足项、差距项与补偿措施
5. 在 **学习总结** 中收束要点并形成统一表达

### 岗位训练路径

适合销售、产品经理、FAE 和 TS 按岗位目标学习。

1. 先阅读案例背景和客户输入
2. 按岗位重点关注方案、能力或差距解释
3. 用学习总结复盘常见误区、关键话术和跨团队协作点

## 页面说明

- **首页**：说明平台定位、适合角色和推荐使用方式
- **学习总览**：查看案例背景、阶段进度和学习入口
- **客户诉求**：理解客户担忧、业务场景和关键输入
- **方案转译**：理解如何从诉求形成分区、边界和能力需求
- **能力说明**：理解产品能力如何映射到案例需求
- **差距分析**：理解满足项、部分满足、外部补偿与闭环动作
- **追溯视图**：理解输入、设计、能力和输出之间的关系
- **学习总结**：汇总案例结论并沉淀可复用的表达
- **平台用法**：说明推荐使用路径和学习边界

## 系统优势

### 1. 用案例降低学习门槛

用户不必先掌握完整条文体系，而是通过具体项目情境理解 IEC 62443 的实际表达方式。

### 2. 用岗位视角提升吸收效率

同一案例可以分别服务销售、产品经理、FAE 和 TS，让每个岗位都知道自己该关注什么。

### 3. 用链路帮助新人建立项目语感

用户能直观看到客户诉求、方案响应、能力说明和差距处置之间的关系，而不是零散记忆知识点。

### 4. 有利于统一团队对外表达

通过统一的案例和页面结构，团队可以更容易形成一致的话术、边界表达和协作方式。

### 5. 兼顾培训、演示和内部对齐

平台既可用于新人入门，也可用于讲师演示、售前赋能和跨角色讨论。

## 当前边界

本系统是内部学习与案例演示平台，当前不等同于正式工程系统。

请注意：

- 系统输出不构成正式风险评估结论
- 系统输出不构成认证、合规或审计结论
- 系统输出不替代详细工程设计、专家评审或现场验证
- 案例内容主要用于训练和演示，需要结合真实项目背景复核
- 演示数据为示例，不代表任何真实企业、真实项目或官方背书
